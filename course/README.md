# Python Principal Engineer Masterclass

A complete Python course designed for engineers who want to grow from Python beginner to Principal-level Python engineer.

This course is intentionally deep. It does not treat Python as only a scripting language. It covers the language, runtime, testing, packaging, architecture, performance, distributed systems, AI engineering, and engineering leadership.

## Audience

- Developers learning Python seriously
- Senior engineers moving into Python-heavy systems
- Tech leads and principal engineers
- Backend engineers building APIs, workers, agents, data pipelines, and distributed systems

## Volumes

1. **Volume 1 — Beginner:** syntax, types, functions, collections, modules, files, OOP, testing, and first projects.
2. **Volume 2 — Intermediate:** typing, decorators, generators, context managers, concurrency, asyncio, databases, packaging, APIs, logging, profiling.
3. **Volume 3 — Advanced / Principal:** CPython internals, performance, architecture, distributed systems, security, AI agents, RAG, Kubernetes, observability, leadership.

## How to study

Each chapter should be studied in this order:

1. Read the learning objectives.
2. Run every code example.
3. Modify examples until they break, then fix them.
4. Complete exercises without looking at solutions.
5. Review the solution and compare trade-offs.
6. Answer the quiz and interview questions.
7. Build the related project milestone.

## Course philosophy

This course teaches Python as a professional engineering platform.

You will learn not only *how* to write Python, but also:

- why the language behaves the way it does,
- how CPython represents objects,
- how memory and references work,
- how to design maintainable systems,
- how to test production applications,
- how to profile and optimize code,
- how to build deployable services,
- how to make architecture decisions at Principal level.
